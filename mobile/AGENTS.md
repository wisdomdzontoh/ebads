# Expo SDK 56

This project targets **Expo SDK 56** (the latest stable SDK that store Expo Go supports).
Read the versioned docs at https://docs.expo.dev/versions/v56.0.0/ before writing native code.

Dependencies are pinned to the SDK-56 set (react-native 0.85.3, react 19.2.3). Keep them
consistent — a plain `npm install` must resolve **without `--legacy-peer-deps`**. Do not
bump individual native modules to SDK 57 versions.
